# Smart Contracts

Solidity smart contracts for onchain age verification.

## Contract: AgeVerification.sol

Verifies ZK proofs generated by the proof server and stores validation results onchain.

## Quick Start

### 1. Install Dependencies

```bash
npm install
# or
yarn install
```

### 2. Get Verification Key

```bash
curl http://localhost:3000/proof/vkey
```

Or from circuit:
```bash
cd ../circuits/script
cargo run --release --bin vkey
```

### 3. Deploy Contract

```bash
# Set vkey
export VKEY="0x00a43d8424d369ae4eb7740d7a006ce78458458a9185c58932d79ddf4b366052"

# Deploy to local network
npm run deploy:local

# Or deploy to testnet
npm run deploy:sepolia
```

### 4. Test Contract

```bash
npm test
```

## Contract Functions

### `verifyAgeProof(proof, publicValues, documentNumberHash)`

Main function - verifies proof and stores result.

**Parameters:**
- `proof` (bytes): Proof from server (hex-encoded)
- `publicValues` (bytes): Public values from server (hex-encoded)
- `documentNumberHash` (bytes32): Keccak256 hash of document number

**Returns:**
- `isValid` (bool): Whether passport is valid
- `meetsAgeRequirement` (bool): Whether age requirement is met

### `verifyProofOnly(proof, publicValues)`

View function - verifies proof without storing (no gas cost).

### `getProofRecord(documentNumberHash)`

View function - retrieves stored proof record.

### `isDocumentNumberUsed(documentNumberHash)`

View function - checks if document number already verified.

### `getUserProofs(userAddress)`

View function - gets all proof hashes for a user.

## Events

### `AgeProofVerified`

Emitted when proof is successfully verified.

```solidity
event AgeProofVerified(
    address indexed user,
    bytes32 indexed documentNumberHash,
    bool isValid,
    bool meetsAgeRequirement,
    uint256 timestamp
);
```

### `ProofRejected`

Emitted when proof is rejected.

```solidity
event ProofRejected(
    address indexed user,
    bytes32 indexed documentNumberHash,
    string reason
);
```

## Frontend Integration

See `frontend_integration.js` for complete example.

**Basic usage:**
```javascript
// 1. Generate proof (offchain)
const proof = await generateProofFromServer(passportData);

// 2. Submit to contract
const tx = await contract.verifyAgeProof(
  proof.proof,
  proof.public_values,
  documentNumberHash
);

// 3. Wait for confirmation
const receipt = await tx.wait();
```

## Gas Costs

- **Proof Verification:** ~200K gas (Groth16)
- **Storage:** ~20K gas
- **Total:** ~220K gas per verification
